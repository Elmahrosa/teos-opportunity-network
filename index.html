Teos Opportunity Network

Deterministic opportunity scanner

Teos Opportunity Network is a deterministic opportunity scanner. It ingests opportunities (currently GitHub bounties), normalizes and deduplicates them by content hash, and scores each one 0–100 against user profiles using fixed, versioned weights (HYBRID_V1). It alerts via Telegram only when a score clears a fixed bar: ≥85 = ALERT, ≥90 = APPLY_NOW. Scores below the bar are logged, never notified.

The repository also ships a deterministic GitHub repository valuation engine as a GitHub Actions composite action (action.yml): it scores a repository 0–100, estimates a value range, and maps the result to a decision band (ALERT / LOG / IGNORE). It is fully deterministic — no LLM calls.

Everything on this page is backed by the codebase and its automated test suite (unit + real-PostgreSQL integration):

  • Deterministic 0–100 scoring with fixed thresholds (≥85 ALERT, ≥90 APPLY_NOW).
  • Idempotent deduplication — re-ingesting the same source record never duplicates it.
  • Snapshot-based replay and audit — append-only evidence; replay re-uses stored scores and never re-calls the LLM.
  • Telegram delivery with retry/backoff and at most one sent delivery per match.
  • Dry-run mode — the full pipeline runs end-to-end without a bot token.
  • Telegram bot controls: /start, /pause, /resume.
